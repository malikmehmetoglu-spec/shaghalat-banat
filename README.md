# شغلات بنات

متجر إلكتروني (ويب + PWA قابل للتثبيت) لمتجر «شغلات بنات» في سوريا، مع لوحة إدارة ومخزون موحّد للمتجر الإلكتروني والمحل، ومحاسبة.
مبني بـ **Next.js 15** و **Supabase**، بالعربية (RTL) وبخط Rubik، حسب نظام التصميم المعتمد.

> **الحالة: المرحلة 1 من 4 — متجر العميلة.**

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # القيم جاهزة لمشروع Supabase الحالي
npm run dev                  # http://localhost:3000
```

## النشر على Vercel (موصى به)

1. ادخلي إلى vercel.com ← **Add New Project** ← اختاري مستودع `shaghalat-banat`.
2. في **Environment Variables** أضيفي المتغيرين من ملف `.env.example`.
3. اضغطي **Deploy**. كل رفع جديد على `main` يُنشر تلقائياً.

## إعداد Supabase

قاعدة البيانات **مُنشأة ومُعبّأة ببيانات تجريبية** على مشروع `shaghalat-banat`. ملفاتها للمرجع:

- `supabase/migrations/` — الجداول والصلاحيات (RLS) ودوال الطلب.
- `supabase/seed.sql` — منتجات وأقسام ومخزون تجريبي (تُستبدل لاحقاً من لوحة الإدارة).

### خطوات مطلوبة منكِ في لوحة Supabase

1. **رابط الموقع للدخول بالبريد:** Authentication ← URL Configuration ← ضعي رابط الموقع بعد النشر في **Site URL**، وأضيفي `https://<رابط-الموقع>/auth/callback` في **Redirect URLs**.
2. **الدخول برقم الهاتف (SMS):** Authentication ← Providers ← Phone ← فعّليه واربطيه بمزوّد رسائل (مثل Twilio أو Vonage أو MessageBird) يدعم الأرقام السورية. حتى يتم ذلك، الدخول بالبريد يعمل مباشرة.
3. **أول حساب إدارة:** بعد أن تسجّلي دخولك مرة، نفّذي في SQL Editor:
   ```sql
   update public.profiles set role = 'owner' where email = 'بريدك@example.com';
   ```

## هيكل المشروع

```
src/
  app/
    (shop)/      صفحات فيها الشريط السفلي: الرئيسية، الأقسام، المفضلة، حسابي، الطلبات، الإشعارات
    (focus)/     صفحات بلا شريط سفلي: المنتج، القسم، البحث، السلة، الدفع، الدخول…
    auth/callback  عودة رابط الدخول من البريد
  components/    المكونات المشتركة (بطاقة المنتج، الشريط السفلي، الأيقونات…)
  lib/           الاتصال بـ Supabase، جلب البيانات، تنسيق الأسعار والتواريخ
supabase/        مخطط قاعدة البيانات والبيانات التجريبية
public/          الشعار، أيقونات التطبيق، Service Worker
```

## قواعد ثابتة في الكود

- العملة **ليرة سورية** وتُكتب `450 ل.س`؛ **الأرقام إنجليزية دائماً** (`src/lib/format.ts`).
- الخط **Rubik** فقط، والألوان والمسافات من نظام التصميم (`src/app/globals.css`).
- لا أشرطة تمرير ظاهرة، ولا ارتفاعات ثابتة على حاويات النصوص، وline-height لا يقل عن 1.4.
- الرفع دائماً على فرع `main`.
