# شغلات بنات

متجر إلكتروني (ويب + PWA قابل للتثبيت) لمتجر «شغلات بنات» في سوريا، مع لوحة إدارة ومخزون موحّد للمتجر الإلكتروني والمحل، ومحاسبة.
مبني بـ **Next.js 15** و **Supabase**، بالعربية (RTL) وبخط Rubik، حسب نظام التصميم المعتمد.

> **الحالة: المرحلة 1 من 4 — متجر العميلة.**

---

## ما يعمل الآن (المرحلة 1)

| إتمام الطلب | `/checkout` | العنوان ← الشحن ← الدفع (عند الاستلام / تحويل) |
| تأكيد وتتبّع الطلب | `/orders/[id]` | خط زمني لحالة الطلب |

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # القيم جاهزة لمشروع Supabase الحالي
npm run dev                  # http://localhost:3000
```

## النشر على Vercel (موصى به)

1. ادخلي إلى vercel.com ← **Add New Project** ← اختاري مستودع `shaghalat-banat`.
2. في **Environment Variables** أضيفي المتغيرين من ملف `.env.example`.
3. اضغطي **Deploy**. كل رفع جديد على `main` يُنشر تلقائياً.

## إعداد Supabase

قاعدة البيانات **مُنشأة ومُعبّأة ببيانات تجريبية** على مشروع `shaghalat-banat`. ملفاتها للمرجع:

- `supabase/migrations/` — الجداول والصلاحيات (RLS) ودوال الطلب.
- `supabase/seed.sql` — منتجات وأقسام ومخزون تجريبي (تُستبدل لاحقاً من لوحة الإدارة).

### خطوات مطلوبة منكِ في لوحة Supabase

1. **رابط الموقع للدخول بالبريد:** Authentication ← URL Configuration ← ضعي رابط الموقع بعد النشر في **Site URL**، وأضيفي `https://<رابط-الموقع>/auth/callback` في **Redirect URLs**.
2. **الدخول برقم الهاتف (SMS):** Authentication ← Providers ← Phone ← فعّليه واربطيه بمزوّد رسائل (مثل Twilio أو Vonage أو MessageBird) يدعم الأرقام السورية. حتى يتم ذلك، الدخول بالبريد يعمل مباشرة.
3. **أول حساب إدارة:** بعد أن تسجّلي دخولك مرة، نفّذي في SQL Editor:
   ```sql
   update public.profiles set role = 'owner' where email = 'بريدك@example.com';
   ```

## هيكل المشروع

```
src/
  app/
    (shop)/      صفحات فيها الشريط السفلي: الرئيسية، الأقسام، المفضلة، حسابي، الطلبات، الإشعارات
    (focus)/     صفحات بلا شريط سفلي: المنتج، القسم، البحث، السلة، الدفع، الدخول…
    auth/callback  عودة رابط الدخول من البريد
  components/    المكونات المشتركة (بطاقة المنتج، الشريط السفلي، الأيقونات…)
  lib/           الاتصال بـ Supabase، جلب البيانات، تنسيق الأسعار والتواريخ
supabase/        مخطط قاعدة البيانات والبيانات التجريبية
public/          الشعار، أيقونات التطبيق، Service Worker
```

## قواعد ثابتة في الكود

- العملة **ليرة سورية** وتُكتب `450 ل.س`؛ **الأرقام إنجليزية دائماً** (`src/lib/format.ts`).

## المرحلة 2 — لوحة الإدارة والمخزون

افتحي `/admin` بحساب دوره ليس «عميلة». الأقسام: لوحة المؤشرات، الطلبات، العملاء، نقطة البيع، المنتجات، الأقسام والبانرات، الكوبونات، المخزون (نظرة عامة، الحركات والتحويل، الجرد، تنبيهات النقص، الموردون وأوامر الشراء)، الباركود والملصقات، الموظفون والأدوار.

نفّذي ملفات `supabase/migrations/0003_admin_inventory.sql` و`0004_role_guard.sql` بالترتيب في محرر SQL إن لم تكن مطبّقة. الملف 0004 يمنع أي موظفة غير المديرة من تغيير الأدوار.

## المرحلة 3 — المالية والمحاسبة

نفّذي `supabase/migrations/0005_finance.sql` في SQL Editor (بعد 0004). يضيف: دليل الحسابات، القيود اليومية (قيد مزدوج)، المصاريف مع الإيصالات، ورديات المحل، الإعدادات المالية، وطلبات الإرجاع.

الأتمتة:
- تسليم طلب أونلاين أو بيع في المحل ← قيد مبيعات + تكلفة البضاعة (من «التكلفة» في بطاقة المنتج).
- تغيير الطلب إلى «مُرتجع» ← قيد عكسي.
- استلام أمر شراء ← المخزون مدين / ذمم المورد دائن، وتحديث تكلفة المنتج.
- الدفع عند الاستلام يبقى في «ذمم شركة التوصيل» حتى تسجيل التحصيل من صفحة الذمم.

قسم المالية يظهر للمديرة والمحاسبة فقط.

## المرحلة 4 — الإشعارات، تطبيق الجوال، الإنجليزية

### 1) قاعدة البيانات
نفّذي `supabase/migrations/0006_push.sql` في SQL Editor.

### 2) إشعارات المتصفح والـ PWA (Web Push)
في Vercel ← Settings ← Environment Variables أضيفي `VAPID_PRIVATE_KEY` (المفتاح الخاص أُرسل لكِ في المحادثة؛ لا يوضع في المستودع)، ثم أعيدي النشر.
العميلة تفعّل الإشعارات من «حسابي ← الإعدادات» أو بعد إتمام الطلب. على iPhone يجب إضافة الموقع إلى الشاشة الرئيسية أولاً (iOS 16.4+).

يُرسل تلقائياً: تأكيد الطلب، الشحن، التوصيل، الإلغاء. والحملات من «لوحة الإدارة ← إرسال الإشعارات».

**الإشعارات المجدولة:** تُرسل عند فتح صفحة الإشعارات في اللوحة، أو تلقائياً عبر خدمة مجانية مثل cron-job.org تستدعي كل 10 دقائق:
`https://<موقعك>/api/push/cron?key=<CRON_SECRET>` — بعد إضافة `CRON_SECRET` (أي كلمة سر) و`SUPABASE_SERVICE_ROLE_KEY` (من Supabase ← Settings ← API) في Vercel.

### 3) تطبيق Android / iOS (Capacitor)
التطبيق يغلّف الموقع المنشور، فأي تحديث على الموقع يظهر فوراً في التطبيق.
1. عدّلي `server.url` في `capacitor.config.ts` (أو `CAP_SERVER_URL`) إلى رابط موقعك.
2. Android: ثبّتي Android Studio ثم `npm run cap:android`. iOS (على Mac مع Xcode): `npm run cap:ios`.
3. إشعارات التطبيق (FCM): أنشئي مشروع Firebase، أضيفي تطبيق Android بالمعرّف `com.shaghalatbanat.app` وضعي `google-services.json` في `android/app/`، ولـ iOS ارفعي مفتاح APNs في Firebase. ثم أنشئي Service Account من Firebase ← Project settings ← Service accounts وضعي محتوى ملف JSON كاملاً في متغير `FCM_SERVICE_ACCOUNT` على Vercel.

### 4) اللغة الإنجليزية
واجهة العميلات تدعم الإنجليزية (من «حسابي ← الإعدادات ← اللغة») مع الاتجاه من اليسار لليمين. الترجمات في `src/lib/i18n/en.ts` (المفتاح هو النص العربي). أسماء المنتجات والأقسام تظهر بالإنجليزية إن عُبّئ حقل «الاسم بالإنجليزية». لوحة الإدارة تبقى بالعربية.
